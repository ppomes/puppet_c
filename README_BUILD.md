# Build Instructions

This project supports two build systems:

## 1. Autotools (Recommended)

Professional build system with automatic dependency detection:

```bash
# First time setup
./autogen.sh

# Configure with custom Ruby path (recommended)
./configure --with-ruby=/opt/homebrew/opt/ruby

# Or configure with auto-detected Ruby
./configure --enable-ruby

# Build and test
make
make check

# Install system-wide (optional)
sudo make install

# Create distribution tarball
make dist
```

**Configure Options:**
- `--with-ruby=PATH` - Specify Ruby installation path
- `--enable-ruby` - Enable Ruby/ERB support (auto-detect)
- `--disable-ruby` - Disable Ruby support
- `--enable-debug` - Enable debug mode

## 2. Simple Makefile

For quick development builds:

```bash
# Build with simple Makefile
make -f Makefile.simple

# Test with simple Makefile
make -f Makefile.simple test

# Clean
make -f Makefile.simple clean
```

**Note:** The simple Makefile has hardcoded Ruby paths for Homebrew. Edit `Makefile.simple` to adjust paths if needed.

## Requirements

- **flex** and **bison** - Parser generators
- **GCC** or compatible C compiler
- **Ruby 3.4+** (optional, for ERB template support)

### Installing Dependencies

**macOS (Homebrew):**
```bash
brew install ruby flex bison
```

**Ubuntu/Debian:**
```bash
apt-get install ruby-dev flex bison build-essential
```

## Generated Files

The following files are generated during build and excluded from git:
- `Makefile` (generated by autotools)
- `configure` (generated by autotools)
- `src/puppetc`, `bin/puppetc` (executables)
- `src/lex.yy.c`, `src/puppet.tab.c` (generated parsers)
- `*.tar.gz` (distribution tarballs)
